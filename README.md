# Makhinjauri Bakery & Café — GitHub Pages

Статическая версия сайта для GitHub Pages.

## Что работает

- переход «категории → позиции»;
- корзина-счётчик;
- адаптивная верстка;
- сгенерированные временные фото;
- секции доставки, о кафе и заказа.

## Публикация

Workflow `.github/workflows/pages.yml` публикует содержимое корня репозитория в GitHub Pages при push в `master`.

В GitHub откройте **Settings → Pages → Source → GitHub Actions** один раз для нового репозитория.
